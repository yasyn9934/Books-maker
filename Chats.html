الروابط المضافة

ℹ️ شرح تنسيق JSON

يمكن استيراد ملف JSON يحتوي على مصفوفة من الرسائل أو على كائن محادثة كامل. تنسيق كل رسالة:

[
  { "id":"m1", "name":"أحمد", "text":"مرحبا" },
  { "id":"m2", "name":"أنا", "text":"وعليكم السلام", "Rep":"m1" },
  {
    "id":"m3", "name":"أحمد",
    "text":"آية: ﴿إنا أعطيناك الكوثر ۝﴾ وحديث: «الأعمال بالنيات»",
    "chat":{ "Id":"c1", "Loc":"أحمد", "name":"محادثة خاصة" }
  },
  { "id":"m4", "name":"مشرف", "text":"إعلان",
    "chat":{ "Id":"g1", "name":"الإعلانات العامة" } }
]

الحقول:

id معرّف فريد · name اسم المرسل (أنا = رسائل صادرة) · text النص · Rep معرّف رسالة يُرد عليها · chat محادثة فرعية (اختياري)
