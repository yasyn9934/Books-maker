الروابط المضافة

ℹ️ شرح تنسيق JSON

يمكن استيراد ملف JSON يحتوي على مصفوفة من الرسائل، أو على محادثة كاملة، أو على عدة محادثات مع ملفات أعضائها. تنسيق الرسائل:

[
  { "id":"m1", "name":"أحمد", "text":"مرحبا" },
  { "id":"m2", "name":"أنا", "text":"وعليكم السلام", "Rep":"m1" },
  { "id":"m3", "name":"سارة", "type":"post",
    "text":"منشور فيه صورة",
    "imgs":[ { "src":"data:image/jpeg;base64,...",
               "name":"لقطة",
               "caption":"تعليقي على الصورة",
               "transcript":"النص الظاهر في الصورة" } ] },
  { "id":"m4", "type":"note", "text":"تعليق توضيحي مني" },
  { "id":"m5", "name":"مشرف", "text":"إعلان",
    "chat":{ "Id":"g1", "name":"الإعلانات العامة" } }
]

الحقول:

id معرّف فريد · name اسم المرسل (أنا = رسائل صادرة) · text النص · Rep معرّف رسالة يُرد عليها · chat محادثة فرعية · type نوع النص: reply رد (الافتراضي) أو comment تعليق أو post منشور أو note تعليق توضيحي (بلا مرسل) · imgs مصفوفة صور، لكل صورة src (رابط أو data URL) وname وcaption وtranscript

ملف المحادثات الكامل:

{"format":"tg-viewer","version":4,"conversations":[],"profiles":{}}

🎨 تغيير ثيم التطبيق

اختر أحد الألوان العشرين، وسيُطبَّق فورًا على كامل التطبيق (الرأسية، الفقاعات، الأزرار، والخلفيات) بما يتوافق مع الوضع الفاتح أو الداكن الحالي.

🪪 الملف الشخصي

الألوان مميزة عالميًا؛ اختيار لون مستخدم ينقل اللون السابق بين الطرفين.
وصف تحليلي معمّق
لا يوجد وصف تحليلي بعد.
أوصاف مختصرة / وسوم
الوسوم مرنة العرض، وتحفظ ضمن ملف الطرف في جميع محادثاته.
العلاقات المستخرجة آليًا
الحساب يستند إلى الأسماء والرسائل في الملف فقط؛ لا توجد طوابع زمنية، لذا طول المحادثة يعني عدد الرسائل لا مدتها.

إضافة عضو

تحليل اختياري بالذكاء الاصطناعي

سيتم إرسال نصوص المحادثات المحددة وأسماء المشاركين وأسماء المحادثات، إضافة إلى تعليقات الصور والتفريغ النصي المتاح، إلى عنوان واجهة الذكاء الاصطناعي الذي تختاره. لا تُرسل الصور الأصلية ولا تُحفظ المحادثات على خادم هذا الملف. قد يحتفظ مزود الخدمة بالبيانات وفق سياسته. لا تتابع إن لم تكن مخولًا بمشاركة هذه البيانات.
